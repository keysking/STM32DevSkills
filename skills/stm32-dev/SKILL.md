# STM32 开发入口

本入口默认全局安装；由它安装的系列包则默认工程级安装。使用原生命令完成识别和安装，随后按系列技能继续用户原任务。保留用户选择的工具链与任务范围。

## 1. 确定目标

按 **用户明确指定 → 当前工程配置 → ST-Link 探测 → 询问用户** 的顺序确定系列。识别到 F1 或 C5 即可选择包，不必先取得完整料号。

**ST-Link 结果只用于选择系列包，不作为确定具体型号的依据。** `Device name` 可能包含多个候选型号；Device ID、容量及修订号也不能擅自组合成准确料号。保留工具返回的候选组，例如 `STM32F101/F102/F103` 只能据此选择 F1，不能自行确定为 F103。

- 用户给出 `F103`、`STM32F103C8T6` 等型号时直接映射；修改已有工程时留意目标是否冲突。
- 未提供型号时，按[工程识别](references/identify.md)读取当前工程的实际配置，排除 SDK、示例、历史产物中的其他型号。
- 工程信息不足时，按[环境发现与 ST-Link 探测](references/probe.md)查找 Cube / CubeProgrammer，绑定探针并读取目标信息。目标已明确时无需探测。
- 多个候选工程或探针无法选择、用户目标与工程冲突、最终仍无法识别时，集中说明证据并询问型号或目标。不要以已连接的另一块板覆盖工程目标。

## 2. 选择系列包

| 系列及输入示例 | 技能前缀 | Gitee | GitHub |
| --- | --- | --- | --- |
| STM32F1：`F1`、`F103`、`STM32F103C8T6` | `stm32f1` | [STM32F1DevSkills](https://gitee.com/keysking/STM32F1DevSkills) | [STM32F1DevSkills](https://github.com/keysking/STM32F1DevSkills) |
| STM32C5：`C5`、`C532`、`STM32C532CCT6` | `stm32c5` | [STM32C5DevSkills](https://gitee.com/keysking/STM32C5DevSkills) | [STM32C5DevSkills](https://github.com/keysking/STM32C5DevSkills) |

仅上述系列已提供包。其他系列明确说明暂未提供对应包，不下载相近系列，也不按字符串拼接猜测仓库。系列包自身的工具链和任务范围仍适用，例如 F1 包当前面向 CMake 工程。

中文对话优先 Gitee，其他语言默认 GitHub；首选源不可访问时尝试另一来源，遵从用户明确指定的来源限制。

## 3. 在工程中安装或复用

按[下载与安装](references/install.md)确定本次工程根目录及客户端技能目录。

- 当前工程已有完整的对应系列包：直接使用，不检查远端更新。
- 尚未安装：下载选定仓库，检查七个技能及其参考资料，整包复制到工程级技能目录。
- 已有同名目录但内容不完整：先比较缺失与本地修改，不覆盖、混合版本或删除用户内容。说明冲突后确定修复方式。

## 4. 继续原任务

核对安装后的实际文件，读取对应技能的 `SKILL.md`，再按其要求读取参考资料。选择前缀后的职责：

| 用户当前任务 | 首先读取 |
| --- | --- |
| 准备或修复开发环境 | `*-env` |
| 新建、接手或整理工程 | `*-project` |
| 配置引脚、时钟、外设或生成代码 | `*-configure` |
| 编写应用、移植驱动或 FreeRTOS 功能 | `*-firmware` |
| 构建与编译链接问题 | `*-build` |
| 烧录、校验与启动 | `*-flash` |
| 板端运行故障与调试 | `*-debug` |

例如用户只提供 F103 时，可以先安装并读取 `stm32f1-project/SKILL.md`。**新建工程必须先确定准确芯片型号**，包括选型需要的封装和容量；创建目标相关配置或生成工程前，从用户明确提供的信息或本次任务的工程配置取得具体料号。用户未提供、工程中也没有时，询问用户并等待答案，不能用 ST-Link 候选组、示例型号或默认值补齐。安装系列包本身不因缺少准确料号而阻塞。

其他任务在执行到需要准确型号的步骤时采用同样规则；只需选择系列包或阅读资料时，无需提前追问。继续工作时不要求用户重新描述原任务，也不把“下载完成”作为原任务完成。客户端自动发现与文件读取是两回事；仅在实际需要且客户端未发现新技能时说明重新加载方法，不声称已经注册或启用。
