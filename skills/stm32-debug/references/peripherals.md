# 外设、中断与 DMA 定位

按数据从应用到硬件再返回的路径检查，而不是一次改动多个不相关参数。

| 层次 | 证据与问题 |
| --- | --- |
| 应用调用 | API 是否真实执行、传入哪个实例、返回值、计数、超时和缓冲区生命周期。 |
| 初始化 | 初始化状态、句柄、模块宏、复位/时钟门控、实际生成文件和调用顺序。 |
| 时钟与引脚 | 真实输入源、外设时钟、复用、电气配置、板卡接线和物理收发器。 |
| 外设状态 | 使能、状态和错误标志、FIFO、触发源、地址/滤波/协议参数。 |
| DMA | 请求与通道/流、传输计数、地址、宽度、内存可达性、cache 和错误标志。 |
| IRQ/回调 | 向量、NVIC、屏蔽状态、优先级、实际 ISR、驱动处理函数和完成/错误回调。 |
| 外部信号 | 逻辑分析仪/示波器、串口或协议响应，与软件计数及状态对应。 |

中断不触发时沿外设标志 → 中断使能 → NVIC pending/enable → CPU 屏蔽/优先级 → 向量符号检查。回调不执行时检查弱符号覆盖、C/C++ 名字修饰、实例与 handler 关联。

DMA 完成不代表应用已看到完整数据；检查循环缓冲区边界、空闲/半传输回调、缓存维护、重复启动和并发访问。观察 DMA count、错误以及目标内存是否真正变化。

I2C 无响应还要检查上拉、电平与实际总线状态；SPI 检查模式、片选和数据宽度；UART 检查波特率、方向与电平；CAN/FDCAN 检查位时序、收发器、终端、电缆、ACK 和总线错误。具体数值由当前芯片与板卡确定。

低功耗后故障检查时钟恢复、外设唤醒、引脚状态和 tick；带缓存、多核、安全域的系统还需检查内存属性及访问权限。暂停观察会改变时序，必要时用计数、trace 或外部仪器补充。

一次只改变与当前假设相关的条件，用同一收发或触发条件复查。缺少硬件时清楚列出需要的信号或状态，继续检查配置、源码和构建产物。
